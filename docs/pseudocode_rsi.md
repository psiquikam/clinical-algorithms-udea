# Pseudocódigo — Intubación en Secuencia Rápida (RSI)

1. Recibir un paciente simulado.
2. Evaluar dificultad de vía aérea con el esquema implementado.
3. Seleccionar agente de inducción según las condiciones codificadas.
4. Seleccionar bloqueante neuromuscular.
5. Calcular las dosis a partir del peso.
6. Generar preparación, ejecución, plan de rescate y manejo post-intubación.
7. Presentar alertas y resultados para simulación y docencia.

> Implementación correspondiente al módulo `algorithms/rsi.py`.
