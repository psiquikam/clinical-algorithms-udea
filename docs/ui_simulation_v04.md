# v0.4 — Sala de reanimación interactiva

Esta versión añade una interfaz 2D orientada a simulación: paciente virtual, monitor fisiológico,
estado de conciencia, intervenciones, trayectoria y debriefing.

## Principio pedagógico

La interfaz evita centrar la actividad en una pregunta con una única respuesta. El estudiante
observa, actúa, interpreta el cambio fisiológico y vuelve a decidir.

## Identidad visual

La interfaz usa una paleta inspirada en la identidad visual institucional de la Universidad de
Antioquia. No se distribuyen ni se incrustan archivos de logos oficiales en esta versión. El uso
del logosímbolo oficial debe ajustarse al Manual de Identidad Institucional y a las autorizaciones
correspondientes.

## Alcance

Las variaciones fisiológicas son **simuladas** y tienen finalidad exclusivamente educativa. No
representan una predicción clínica ni deben emplearse para orientar atención real.
