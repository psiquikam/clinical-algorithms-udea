# v0.5 — Sala de reanimación interactiva

Esta versión profundiza la experiencia de simulación: el estudiante puede observar, solicitar información, intervenir y reevaluar. La sesión conserva una trayectoria de decisiones y el estado fisiológico simulado se actualiza tras cada acción.

## Cambios frente a v0.4.1

- Acciones organizadas en cuatro modos: observar, solicitar, intervenir y reevaluar.
- Información clínica bajo demanda.
- Eventos temporales del escenario.
- Respuesta del paciente y del monitor tras las acciones.
- Tendencia de PAM y lactato para apoyar el razonamiento longitudinal.
- Registro de trayectoria y debriefing de cierre.
- Compatibilidad conservada con la API de la v0.3/v0.4.1 para reducir regresiones.

## Alcance pedagógico

El objetivo es desplazar la experiencia desde la selección de una respuesta hacia la gestión de un estado clínico cambiante. Las variaciones fisiológicas son simuladas, deliberadamente simplificadas y no predictivas.
